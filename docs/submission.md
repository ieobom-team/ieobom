# 제출 체크리스트

대회 제출 요건 중 **저장소·배포와 관련된 것만** 모아 둔다.
발표·IR·영상 준비는 팀 운영 문서(Notion)에서 관리한다.

## 마감

**2026-08-21 (금) 09:59**

## 저장소 요건

- [ ] 저장소가 **Public**이다
- [ ] 평가 기준 브랜치가 **`main`**이다
- [ ] 제출한 저장소·브랜치가 **배포 링크와 실제로 연동돼 있다** (연동 안 되면 감점)
- [ ] 팀당 최대 3개 저장소. **모노레포 하나로 개발했으므로 프론트/백 두 칸에 같은 URL을 중복 기입한다**
- [ ] API 키·토큰·`.env`가 커밋되지 않았다 (Public 저장소 — CI `guard` 잡이 검사)

> **제출 이후 코드 수정 불가.** 마감 후 수정이 적발되면 즉시 탈락이다.
> 마감 전에 `main`을 최종 상태로 만들어 두고 그 뒤로는 건드리지 않는다.

## 배포 요건

- [ ] 배포 링크에서 **핵심 기능이 실제로 작동한다**
      (실현 가능성 배점이 "아이디어"가 아니라 "배포되어 작동함"을 본다)
- [ ] 로그인은 만들지 않는 것이 원칙이다. 불가피하면 **테스트 계정을 함께 제출**한다
- [ ] 배포 환경의 DB·LLM 키가 환경변수로 주입돼 있다

## 코어 플로우 확인

배포 링크에서 아래가 끊기지 않고 이어지는지 확인한다.

1. [ ] 인계 입력 (텍스트)
2. [ ] AI 구조화 → 어르신별 카드 생성
3. [ ] 카드 항목에 **근거 원문**이 함께 보임
4. [ ] 다음 행동에 담당자가 붙음
5. [ ] 미처리 → 완료 상태 변경 (대리 완료 포함)
6. [ ] 전산 붙여넣기용 텍스트 복사
